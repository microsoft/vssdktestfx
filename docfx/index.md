# Overview

The Visual Studio SDK Test Framework enables unit tests to exercise Visual Studio
code outside the Visual Studio process.

Install it from NuGet:

[![NuGet package](https://img.shields.io/nuget/v/Microsoft.VisualStudio.Sdk.TestFramework.svg)](https://nuget.org/packages/Microsoft.VisualStudio.Sdk.TestFramework)

```console
dotnet add package Microsoft.VisualStudio.Sdk.TestFramework
```

## Highlights

- Provides core Visual Studio services for unit tests.
- Includes integrations for xUnit v2 and v3.
